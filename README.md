# Master League for eFootball

An external Master League for eFootball on PC, by RBs GameLab & Tom Gibbons.
eFootball has no Master League, so this program runs one next to the game: fixtures, standings,
transfers, player growth, honours and match reports live in the program, and you play the matches
in eFootball.

## Download

Get the latest `Master League x.y.exe` from **[Releases](https://github.com/RBsGameLab/master-league/releases/latest)**.
It is a single file: put it in a folder of its own (your saves are stored next to it).

From 1.6 on, the program tells you when a new version is out and can update itself.
This repository only hosts the released program and its update feed (`latest.json`, signed).

## Upgrading

1. Back up the `saves` folder next to the exe.
2. Quit the game, then run the new exe from the same folder (or a new folder with `saves` copied over).
3. If the release notes say the match-stats plugin changed, click **Plugin → Update plugin** once.
